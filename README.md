# Infinity AI

Infinity AI is an intelligent AI assistant built with React, Vite, Tailwind CSS, Express, and Google Gemini API.

## Features

- **Smart Intelligence**: Powered by advanced AI models with streaming responses.
- **LaTeX Math Support**: Mathematical equations rendered seamlessly using KaTeX and remark-math.
- **Multimodal Intelligence**: Support for PDF, DOCX, TXT documents, and image analysis.
- **Voice Interactions**: Real-time voice recognition input and text-to-speech output.
- **Rich Markdown**: Code syntax highlighting, tables, lists, and interactive code copying.
- **Conversation Management**: Search, pin, rename, delete, export, and import conversation history.
